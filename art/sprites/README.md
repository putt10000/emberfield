# Sprite sheets

One PNG per character. Replace the PNG with real art using the same layout and
nothing else needs to change (adjust `frame_size`, frame counts or fps in the
matching `*_sheet.tres` if your art differs).

Layout (see `entities/shared/sprite_sheet_def.gd`):

- Frames are `32x32` px, feet on the bottom row, character centred horizontally.
- Rows = animations in this order, **4 rows each** in the order down, left, right, up:

| Animation | Rows | Frames | fps | Loops |
|---|---|---|---|---|
| idle   | 0-3   | 2 | 3  | yes |
| walk   | 4-7   | 6 | 10 | yes |
| attack | 8-11  | 4 | 12 | no  |
| hit    | 12-15 | 2 | 10 | no  |
| death  | 16-19 | 4 | 6  | no  |

- Frames go left to right. The sheet is 6 columns wide; unused cells stay empty.
- Import settings: lossless, no mipmaps, nearest filtering is set on the node.

Placeholders are generated by `tools/gen_sprites.sh`.
